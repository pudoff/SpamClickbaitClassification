# Валидация данных и найденные проблемы

Источники фактов: EDA `Datasets/outputs/eda/summary.json` (проверено скриптами
`Datasets/scripts/dataset_eda.py`, `verify_eda.py`), Model Card, ревью концепта (R-36…R-40),
новый демо-пайплайн `FinalProject/demo` (практика В06 курса).

## 1. Данные

`Datasets/df.csv` (Git LFS, 381 594 633 байт, SHA-256 `81f71b60…`): 2 колонки
`text`, `is_spam1_or_clickbait2` (0 normal / 1 spam / 2 clickbait).
~8 Kaggle-корпусов, большей частью машинный перевод на русский (`Helsinki-NLP/opus-mt-en-ru`).

## 3. Проверки перед обучением (validate_dataset)

- схема и допустимые метки {0,1,2};
- отсутствие точных дубликатов после очистки;
- смешанные метки внутри шаблонных групп (тексты, отличающиеся только числами);
- доля очень коротких текстов (<4 слов) ≤ 5%;
- дисбаланс: миноритарный класс ≥ 10%;
- статистика длины (медиана, p95, max) — база для PSI-мониторинга.

## 4. Найденные проблемы и риски (≥3 по требованию задания)

| # | Проблема / риск | Факт | Мера |
|---|---|---|---|
| P-1 | **Завышенные метрики из-за случайного сплита и разных источников классов.** Модель различает источник/длину, а не смысл: медиана длины normal 94, spam 486, clickbait 56 символов | macro-F1 0.935 в раннем ноутбуке со случайным сплитом; после группового сплита — 0.8347 | Групповой сплит по нормализованным группам; итоговая проверка на voice-holdout; в демо — сплит по шаблонным группам |
| P-2 | **Почти-дубликаты между fit/test.** Аудит: 617 из 2059 проверенных тестовых кандидатов имеют сходство ≥95% с fit | выборочная диагностика, не полный подсчёт | MinHash-кластеры в целевом протоколе; в демо — группы по шаблону (числа маскируются); риск задокументирован в Model Card |
| P-3 | **Слабая граница clickbait/normal и короткие тексты.** F1 кликбейта 0.6795 против 0.9275 у спама; на текстах ≤3 слов macro-F1 0.572 | Model Card, срезы по длине; `test_model.py`: 3 из 6 проверок качества падают | Политика отказа; срез коротких реплик в мониторинге; симуляция дрейфа в экспериментах (E-DRIFT) |
| P-4 | **Хрупкость к ссылкам и длине:** добавленная ссылка меняет 16% предсказаний (порог 10%); очень длинный повторённый кликбейт уходит в «обычное» | `Datasets/outputs/test_model.py` (3 failed) | Найденное слабое место задокументировано; нормализация v2 маскирует ссылки КАПСОМ; усечение последовательностей — ограничение |
| P-5 | **Шум разметки:** «не спам» и «не кликбейт» из бинарных корпусов ≠ «обычное»; 1 148 нормализованных групп со смешанными метками остаются внутри одной части сплита | Model Card §3 | Конфликт-лист на ручную разметку; двойная разметка Label Studio в целевом процессе |
| P-6 | **Несовместимость версий sklearn:** LR, обученная не на 1.8.0, работает ненадёжно в образе сервиса | README проекта | Загрузчик проверяет версию и SHA-256; переобучение тренером в контейнере |
| P-7 | **Дрейф домена:** машинный перевод ≠ живая речь; ASR-ошибки не измерены (WER/CER неизвестны) | Model Card §3 | TTS→ASR обогащение (E-2a), voice-holdout ≥400, PSI-мониторинг длины и доли uncertain |

## 5. Воспроизводимость

- seed=42 везде; SHA-256 датасета и `split_id` фиксируются в манифесте/мете;
- словари и обучаемые преобразования строятся только на fit;
- версии нормализации (`notebook-clean-text-v1`, `clean-text-v2`, `demo-clean-v1`) явно
  записываются в метаданные; обучение и инференс используют одну версию;
- эксперименты демо: `FinalProject/experiments/results/results.json` содержит версии
  библиотек, хеш данных, счётчики отсева, размеры сплита и все метрики.
