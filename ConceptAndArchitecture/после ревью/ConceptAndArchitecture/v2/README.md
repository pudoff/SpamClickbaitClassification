# Концепт и архитектура, версия 2.0

Кейс 4 курса NLP: классификация спама и кликбейта в голосовых сообщениях Telegram. Версия от 01.10.2026, **проект для согласования командой**. Срок проекта — 12.12.2026.

Документы версии 1 (материалы Владимира) лежат уровнем выше, в `ConceptAndArchitecture/`, и остаются без изменений. Ниже — итог их ревью и согласованный вариант.

## С чего начать

1. `07-executive-summary.md` — коротко о решениях, план до 12.12, открытые вопросы.
2. `06-decisions-and-roadmap.md` §3.1 — календарь и вехи.
3. Дальше — по своей роли (роли описаны в `05-mlops-and-validation.md` §1).

## Проверка контракта

Из корня репозитория:

```bash
pip install openapi-spec-validator pyyaml
python tools/validate_openapi.py
```

Скрипт проверяет спецификацию, все примеры и 5 заведомо неверных ответов. На 01.10.2026 проверка проходит: 16 примеров, 5 негативных.
